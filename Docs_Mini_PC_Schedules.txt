UPDATING SCHEDULES ON THE MINI PC

If you ever add a new crawler or change the days/times a crawler runs:
1. Make the changes to setup_task.ps1 on your Main PC and push to GitHub.
2. On the MINI PC, run 'git pull' to download the updated setup script.
3. On the MINI PC, right-click setup_task.ps1 in File Explorer and select "Run with PowerShell" to update Windows Task Scheduler.
