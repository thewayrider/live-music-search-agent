Start of work: git pull

(If you ever get a file conflict or pull error, this 2-line reset is the foolproof way to instantly match GitHub):

git fetch origin
git reset --hard origin/main

----

FINISH working on a PC (End of session)

git add .
git commit -m "Update site changes"
git push origin main

Dashboard Generator cmd:

npm run dashboard

----

UPDATING SCHEDULES ON THE MINI PC

If you ever add a new crawler or change the days/times a crawler runs:
1. Make the changes to setup_task.ps1 on your Main PC and push to GitHub.
2. On the MINI PC, run 'git pull' to download the updated setup script.
3. On the MINI PC, right-click setup_task.ps1 in File Explorer and select "Run with PowerShell" to update Windows Task Scheduler.

----
Workflow for Future Crawler Additions / Retirements:

Whenever you add or retire a crawler in `live-music-search-agent`:
1. Add or remove its entry in src/utils/metricsAggregator.js`
2. Push to git and run `git pull` on your Mini PC.
3. The next time the crawlers sync to Gist (or when you run a manual sync), your 
Android app will immediately reflect the new crawlers with zero app rebuilds required.

----
RUNNING CRAWLERS MANUALLY (OUT-OF-SCHEDULE RUNS)

If a crawler misses a run (e.g. PC was off) or you want to run one immediately:

Method 1 (File Explorer - Easiest):
1. Navigate to the `live-music-search-agent` folder.
2. Double-click the specific `.bat` file you want to run (e.g. `run_amrap.bat`, `run_listenbrainz.bat`). 
3. A terminal window will open and run the crawler, send the email, and update the Gist automatically.

Method 2 (From the Terminal/IDE):
1. Open a terminal inside the `live-music-search-agent` folder.
2. Type the name of the batch file and hit Enter. For example:
   `.\run_futuremag.bat`
   
Method 3 (Using Windows Task Scheduler):
1. Open Windows Task Scheduler (`taskschd.msc`).
2. Click "Task Scheduler Library".
3. Right-click the specific "LiveMusicSearchAgent_..." task and select "Run".
