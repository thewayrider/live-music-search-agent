# Song Curation Workflow

When working with the live-music-search-agent, keep in mind the user's manual curation workflow for discovered songs.

The 4-stage workflow is:
1. **Discovery**: Crawlers discover new songs.
2. **Selection Stage**: Extensive listening and relistening to the discovered tracks.
3. **New Release Consideration**: Determining if a song will get included in the New Release section.
4. **Spotlight Consideration**: Determining if a song will be included in the Spotlight section (Note: the song MUST be from a new artist to be considered for this section).

This is a manual curation process performed by the user after the agent discovers the songs. Ensure that any system modifications, summaries, or agent interactions acknowledge this process when relevant.
